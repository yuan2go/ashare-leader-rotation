# A 股趋势轮动研究台 v4.0

开发期 2015-01-01 至 2026-11-20。已确认的 16 只种子股配置在 universe.csv。策略使用可核验的行情、开盘参考价、涨跌停及权益事件。ETF 分析独立。附带底稿及数据审计，当前正式全池回放由真实数据覆盖门禁控制。原 v3.1 牧原工程仍是独立研究。

## 运行

需要 Python 3.10+ 和 Node.js 18+。在此目录运行：

    python run.py
    python tests/test_engine.py
    node tests/ui.cjs
    python run.py

导入符合数据契约的 CSV 后运行：

    python run.py --confirm-seeds

一个命令生成四窗绩效及压力、2026 月度换仓、单票体检、矩阵、ETF 前瞻诊断与前缀核验。若 K 线及指数数据合格、ETF 未达标，轮动策略仍可单独运行，ETF 指标继续留空。正式成功运行会调用 Node 逐日核对。累计结果见 results/rotation_research.json。开发期末快照和源文件 SHA-256 见 results/data_audit.json。

双击 rotation_quant_lab_v4_0_offline.html。页面会使用相同的开仓、撤单和持仓规则；本地录入可用 IndexedDB。无持久化权限时，可导出工作数据 JSON。升级到 50 只时更新 universe.csv 及相应上市、日线和权益事件底稿，无需修改代码。bucket 使用已批准的配置，红利和科技成长为雷达的对照桶。

## 输入数据约定

| 文件 | 关键约定 |
| --- | --- |
| universe.csv | code 为六位文本，name、bucket、subsector 由研究者维护 |
| funds.csv | ETF 只分蓝筹或成长，代码保留六位 |
| data/instruments.csv | 代码、真实上市日、最后交易日及交易所来源；正常存续 delisting 留空 |
| data/calendar.csv | 交易所实际市场交易日、自然周最后日标志、公告来源。历史日历另与 v3.1 的 2,887 日索引核对 |
| data/stocks.csv | 未复权 OHLCV、日期、状态、交易所开盘参考价、官方涨跌停价、公司行为来源与行情来源。正常交易填 open；停牌填 suspended 且价格留空 |
| data/actions.csv | ex_date、announce_date、pay_date、share_date；现金为每股元，送转为每股新增比例，来源须可核验。同一日多项先合并 |
| data/index.csv | 000300 未复权价格指数开收盘，逐日记录可信来源 |
| data/etf.csv | 当天基金总份额、每份人民币价格或 NAV、成交额人民币、公告日期；share_scale 为份额折算因子，通常填 1，成交额与份额来源分别填 |

每个来源字段必须如实指向交易所、披露公告、已批准公开接口或已核验底稿。域名格式校验只是第一步。若发行历史包含配股或退市清算，需要补足专门可验证的事件数据。行业指数或 ETF 净申赎的公开样例不能补作单股官方历史。

## 固定口径

- T0 为 MA20 大于 MA60；T1 在 20 周均线等条件满足时翻多，日线改为空头或完整周收盘跌破 20 周均线时关闭。周均线下倾阻止新开状态。
- R1 / R2 / R2_Bucket 每周收盘选股，原仓按前 3、前 5 缓冲。R2 上限为两个 50% 槽位，跨桶版监控实际持仓桶，卖单受阻时推迟会造成重复桶的新买单。
- 停牌或开盘触及相应方向涨跌停均顺延。开盘成交判定完全使用开盘信息，执行量按 100 股；清仓时可卖最后零股。
- 以每股除权参考价拼接因果复权；分红在登记持仓对应的除息日确认应收，按股息到账日转可用现金。送转股到账前计在权益，上市日才可卖。
- 1.8% 现金利息按自然日复利并每日四舍五入到分。指数是比较路径，压力参数不适用。
- 雷达日流仅合计数据齐备、当日已披露的基金；上市前自然空缺。ETF 数据完全独立于自动撮合。

## 已确认种子池与采集

策略文件启用了 SHA-256 对账。默认策略审批状态为 approved。Python 的行情验证与单文件页面使用同一套规则。

    python -m pip install -r requirements.txt
    python fetch_v4_data.py && python run.py --confirm-seeds

- BaoStock 获取证券上市资料、交易日历、未复权行情、显式停牌状态和分红到账字段。东方财富接口提供沪深 300 和 ETF 行情，AKShare 对接沪深交易所日份额。请求有重试、限频、缓存和证据哈希。
- 样本外运行使用 `python fetch_v4_data.py --through YYYY-MM-DD`。日期是最后一个已收盘交易日。之后运行生成器可刷新离线页。四窗仍按冻结截止日期计算。
- `data/verified/stocks.csv`、`instruments.csv`、`actions.csv`、`index.csv`、`etf.csv` 可以补充已核验的交易所、公告或公开接口记录。另可使用 `data/verified/stock_limits.csv`（code,date,limit,upper,lower,reference,source）提供重新上市、特殊无涨跌幅、特殊参考价等例外。以证据覆盖列，数据冲突会保留在日志中。时间和金额约束仍由输入校验执行。
- `data/verified/etf_scales.csv`（code,date,share_scale,source）接收有公告支持的拆分或合并；未证实的异常不自动补写。发布字段缺失时，按实际取得该份额证据的日期入账。ETF 审计各自的覆盖、缺口与有效窗口，个别缺口不会阻断股票回测。
- `data/fetch_warnings.log` 列出现有缺日、除权和接入问题。历史报价与确认过的 2,887 日索引一一对账。当前分发包含沪深 300 已对齐序列和部分实际股票、ETF 底稿。外部接口接入成功及历史证据齐全时，命令才会进入正式回测。
- 无网时可用 `python fetch_v4_data.py --offline` 重建本地已核证行。遇到股票缺日或特殊权益事件无法平账，采集返回非零，并保留已取得的数据与原因。未投递上市公告的日期、未见停牌标记和未确认派发日不会按猜测生成。
- 按面值分解份额和成交金额。网页抽样的 510300 份额和成交额用交易所数据，ETF 估值用新浪转发的单位净值，时点采用本工作区首次核验日。该行不构成连续净流。单槽测算报价另存在 `data/verified/sizing_quotes.csv`，不进入报价回放。
- 双端回归可独立运行 `python tests/test_fetch.py`、`python tests/test_engine.py`、`node tests/parity.cjs` 和 `node tests/ui.cjs`。

## Phase 2 异常闭环和诊断

- 参考价异常会尝试用新浪权益实施清单及明细复核。只有公告日、实际派息或新股上市日均齐全，且参考价误差不超过 ¥0.015，才允许自动补录。人工核对后可使用 `data/verified_actions_override.csv`，列与 `data/actions.csv` 一致。配股认购现金流超出冻结引擎的权益事件格式时，应继续阻断验收。
- BaoStock 明确报为开市且 OHLC 异常时，使用东方财富独立价格数据复核。单源缺日会保留缺口。停牌、复牌特殊价格限制只能由独立公告支持后通过 `data/verified/stocks.csv` 或 `data/verified/stock_limits.csv` 倒入。
- 采集在写入前校验，冻结期牧原及指数原记录保留。发现上游与冻结底稿不一致，记录在 `fetch_provenance.json` 的 `blockers` 并暂停正式发布。ETF 缓存固定使用首次取得的日期，除非记录携带更早且可核验的发布时间。
- 正式诊断会按逐笔买入回算 R2 动态槽位，分开归因整手余量与买前现金约束，并保留完整逐月暴露、高相关对及 ETF 覆盖。若门禁失败，`results/rotation_research.json` 明示未正式运行，仅附通过验收的独立对照。
