## 离线使用

在仓库根目录用 PowerShell 运行。无参数命令登记或打开正式账本并导出当前状态。第二条命令从已签发的历史切片重做独立验收。第三条命令按交易日顺序提交本地日包，路径为示意。

```powershell
$py = 'data/fetch_cache/runtimes/batch1-py311/Scripts/python.exe'
& $py -B -X utf8 scripts/run_phase3d_valuediv_shadow.py
& $py -B -X utf8 scripts/run_phase3d_valuediv_shadow.py --verify-offline
& $py -B -X utf8 scripts/run_phase3d_valuediv_shadow.py --input D:/receipts/2026-11-23/session.json
```

`shadow.sqlite3` 是权威记录，保存来源清单、逐节输入、决策排序、目标及四个账户的日终状态。一个交易日的四个账户在同一事务内提交。重送同内容、同日期的日包会跳过；已入账内容变更、漏日、缺数据、来源哈希失配或执行代码身份改变会报错。连续多个日包中，先前成功提交的交易日可直接续记。CSV 为可重建的查询结果。

## 日包协议

`session.json` 是 UTF-8 JSON 对象，含 `format="valuediv-session-v1"`、`kind="forward"`、`day="YYYY-MM-DD"`、`sections`。每个节名映射到 `{"file":"opening.json","sha256":"该文件原始字节的小写 SHA-256"}` 一类的文件引用。引用文件位于日包目录内，各含 `source`（可追溯的提供方及原始回执或公告标识）、`known_at`（带时区的实际可用时间）与 `data`。有不同来源或分批送达时，为相应节记录最晚可用时间，并保留原始回执。哈希校验可以发现输入发生变化，披露时点的真实性仍依赖原始来源记录。

| 节 | data 的内容与可用时点 |
| --- | --- |
| calendar | `sessions` 按日期递增，给出上月末至下月首个交易日之间所有已经公告的交易日。开盘前可得，据此识别当日是否完整月最后一个周信号。 |
| membership | `observed` 是上月末最后交易日，`effective` 是本月首个交易日，`codes` 为 300 个带 .SH/.SZ 后缀的代码。入账时点须已公布，当月名单一致。 |
| opening | `day` 和以代码为键的 `rows`。每行含 `status`（open/suspended）、`open`、`pre_close`、`limit`（bounded/unbounded）、`up_limit`、`down_limit`、`industry`。来源时点在集合竞价价格形成后至 09:30。覆盖全部成分和仍持有的调出股。停牌明确列示，开盘价空，参考价取已知权益调整后的结转价。无涨跌幅限制时须明确标记 unbounded。在行业未知时标为 UNKNOWN。 |
| closing | `day`、`rows`，各代码给出 `high`、`low`、`close`，停牌三项为 null。中国市场收盘后、当日结束前取得。 |
| actions | `day`、`events`。截至开盘已知的当日事件清单，确认为空时填空数组。各事件有 `code,id,type,announced,date`，后两者是实施公告日和账务生效日。ex 提供 `ref_cash,holder_cash,bonus,pay_date,share_date`；transfer 提供 `record_date,ratio,share_date`；delist 提供 `last_open,last_close`。日期用 YYYY-MM-DD，金额为元/股、比例为股/股。 |
| factors | 防御信号日必需。`observation_date` 严格为上一交易日，`rows` 覆盖当日开市成分。每行给出 `pe_ttm,dv_ttm` 并保留原始 null；能确认源表无行时整行显式填 null。估值须在信号决策时已经可得，最迟为 T 日结束。 |

历史验收日包的 `kind` 为 `historical_validation`，使用临时数据库。行情、权益条款和估值取真实历史快照；测试程序模拟各节可用时间，以检验增量逻辑。历史对账只衡量工程一致性。

## 读数

| 文件 | 读数与单位 |
| --- | --- |
| daily_comparison.csv | 各资金档每日收盘扣费净值、现金和两账户净值差。累计超额百分点为净值差除以期初本金再乘 100；相对收益率为防御净值除以同期基准净值减一。日超额为两账户各自当日收益率之差。 |
| fills.csv | 每笔股票、方向、原因、信号日、成交股数、价格、费税、滑点、剩余现金、持股数。以开盘价统一估值，逐笔累加费用和滑点，给出该资金档当笔后的累计超额及成交所属账户累计地产盈亏。同一开盘先列防御后列基准，行序只用于复算。新开仓同时列出该笔整手余额。 |
| property_pnl.csv | 名称含“地产”或“房产”的当时行业分类，逐日逐股记录净盈亏，含价格变动、扣费、应收派息和权益股份。已卖清标的当日仍保留。未知行业的累计归因在日表中单列。 |
| lot_idle.csv | 新开仓尝试，包括整手买不起而成交为零。整手余额为可用额度扣除按规则能买到的最大股数及其佣金；百分比分母为该槽目标预算。日表为建账以来全部新开仓尝试的均值。策略预留的 50% 现金独立核算。 |
| corporate_actions.csv | 按账户与公告追踪应收、到账、送转股份锁定/解锁以及退市清算。 |
| offline_acceptance.json | 历史验收日期、逐账户对账笔数、净值与归因，以及输入和执行代码身份。 |

带 `_cents` 后缀的列以人民币分计。地产、其他行业与未知行业的逐股净盈亏之和，每日逐分核对账户净值变动。正式产物与历史验收记录分别保存。
