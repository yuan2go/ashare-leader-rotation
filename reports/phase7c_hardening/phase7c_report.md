## 工程与运维

- 采集器将正常未发布记为 `pending_upstream_publication`（退出 10），将配置、校验、解析及读写错误记为 `collection_error`（退出 1），并把脱敏原因写入状态和错误日志。成功、已有日包及休市均退出 0。运维进程通过子进程执行，各采集非零退出码均原样入账到任务状态并终止后续 Ingest。
- 作业提交支持 `PHASE7A_API_READ_ONLY` 和 `API_READ_ONLY`，同时核验操作请求头、跨站标记及 Origin 或 Referer。API 独立校验冻结文件和锁，拒绝空或前后矛盾的哈希清单。命令行健康检查同步验证 SQLite、354 个保护项、120 项账本身份及 Tushare 配置状态。
- FastAPI 从同一端口提供 API、前端静态资源和 SPA 深链。Playwright 覆盖净值与超额曲线切换、V5 观察徽章、置换角色、刷新深链和 390px 六线卡片。API 通过既有 `timing` 字段传递补验角色，识别签发 M200 行时沿用其方法标识。 [桌面截图](dashboard-desktop.png) · [移动端截图](dashboard-mobile.png)
- CI 保留 Windows / Ubuntu `verify` 矩阵，新增每个 push / PR 运行的 Ubuntu 全栈契约任务。签发输入启用时，矩阵同时运行真实账本 API 套件。GitHub Actions 执行状态需以远端实际运行为准。
