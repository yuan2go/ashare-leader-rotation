# Phase 2B-P2 熊市左尾风控消融

IS 判决为 **M200_HYST_HALF**。216 组独立起跑，11/11 历史锚点与 36/36 组 P1 BASE 的净值、成交文件 SHA-256 均通过。保护范围内 22,341 个文件运行前后哈希一致。

## 执行口径与锁定

每窗起点 ¥450,000。P1 纯 BASE 的防御袖子使用月末最后一个周信号及 50% 预算。本次文字中的半月轮动与归档实现不同，实验采用归档日历以保持 BASE 账本精确复现。趋势 gate、排名、Top-2、keep_rank=4、日度硬离场和波动上限沿用 P1。HALF 将总上限降为 25%，单票取 12.5% 和原波动上限的较小值。ZERO 在应执行日停止新增仓位，已持有仓位按原撮合约束卖出。趋势释放预算不转给防御袖子。恢复正常后沿用 BASE 的建仓与留仓规则。

信号使用 T 日收盘，只在原周频计划上判定。外生状态预热延续 2015 年行情。DD10 以本窗本变体本情景的逐日高水位（含期初本金）计算，只在周信号日判断。弱势周比例和切换以窗内周信号计数，窗前用于边界初次下单的信号不进入统计。
